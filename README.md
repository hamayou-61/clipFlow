# ClipFlow

複数の動画クリップを連結・合成して1つの動画として書き出すデスクトップアプリケーション。

## 特徴

- **セグメント構成**: 動画をセグメント単位で構成し、各セグメントごとにレイアウトを設定
- **3つのレイアウト**: メインのみ / 左右分割 / 上下分割
- **トリミング**: 各クリップのイン点・アウト点を自由に設定
- **クロップ調整**: レイアウトに応じた切り取り位置とズームを調整
- **音量調整**: メイン・サブ各レーンの個別音量とバランスを調整
- **リアルタイムプレビュー**: セグメント切り替えにも対応したプレビュー再生
- **高品質書き出し**: H.264/AAC形式でMP4出力

## 技術スタック

- Electron + React + TypeScript
- Vite (ビルドツール)
- Zustand (状態管理)
- Tailwind CSS (スタイリング)
- FFmpeg (動画処理)

## 開発環境セットアップ

### 必要条件

- Node.js 18以上

```bash
npm install
```

```bash

```

```bash

```

## 使い方

### 基本的な流れ

1. **セグメントを追加**: 「+」ボタンでセグメントを追加
2. **レイアウトを選択**: メインのみ / 左右分割 / 上下分割から選択
3. **動画を設定**: 各レーンにドラッグ&ドロップまたはクリックで動画を追加
4. **トリミング**: クリップを選択し「トリム」タブで使用範囲を調整
5. **クロップ調整**: 「クロップ」タブで表示位置とズームを調整
6. **プレビュー**: 再生ボタンまたはスペースキーで確認
7. **書き出し**: 「書き出し」ボタンから保存先を選択して実行

### セグメント構成

各セグメントは独立したレイアウトを持ち、順番に連結されます：

```
[セグメント1: メインのみ] → [セグメント2: 左右分割] → [セグメント3: 上下分割]
```

### レイアウトタイプ

| タイプ | 説明 | 使用クリップ |
|--------|------|-------------|
| メインのみ | フル画面表示 | メインのみ |
| 左右分割 | 横並び2画面 | メイン（左）+ サブ（右） |
| 上下分割 | 縦積み2画面 | メイン（上）+ サブ（下） |


## 出力仕様

| 設定 | 値 |
|------|-----|
| 解像度 | 1920×1080 (16:9) / 1080×1920 (9:16) |
| 映像コーデック | H.264 (libx264, CRF 23) |
| 音声コーデック | AAC 192kbps |
| コンテナ | MP4 |


## 制限事項

- 各レーン最大10クリップ
- 対応フォーマット: MP4, MOV
- 音量ブースト: 最大200%（プレビュー）/ 300%（エクスポート）
