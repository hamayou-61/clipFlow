# Split Video Editor

2つの動画を左右（または上下）に並べて1つの動画として書き出すデスクトップアプリケーション。

## 主な機能

- **2画面レイアウト**: 左右並び（16:9）または上下積み（9:16）
- **トリミング**: 各クリップのイン点・アウト点を設定
- **クロップ調整**: 表示位置とズーム倍率を調整
- **音量調整**: 左右チャンネルの個別音量とバランス調整
- **リアルタイムプレビュー**: 編集内容を確認しながら作業
- **高品質書き出し**: H.264/AAC形式でMP4出力

## 技術スタック

- Electron + React + TypeScript
- Vite (ビルドツール)
- Zustand (状態管理)
- Tailwind CSS (スタイリング)
- FFmpeg (動画処理)

## 開発環境セットアップ

### 必要条件

- Node.js 18以上
- npm または yarn

### インストール

```bash
# リポジトリをクローン
git clone <repository-url>
cd video-editor

# 依存関係をインストール
npm install
```

### 開発サーバー起動

```bash
npm run dev
```

Electronアプリが起動し、ホットリロードが有効な状態で開発できます。

### ビルド

```bash
# プロダクションビルド
npm run build
```

## 使い方

1. **動画を追加**: 各レーンの「+」ボタンから動画ファイル（MP4/MOV）を選択
2. **トリミング**: クリップを選択し、タイムライン下部のスライダーで範囲を調整
3. **クロップ調整**: クリップを選択し、クロップエディターでドラッグして位置調整
4. **音量調整**: プレビュー下部のスライダーで左右の音量とバランスを調整
5. **プレビュー**: 再生ボタンまたはスペースキーで確認
6. **書き出し**: 「書き出し」ボタンから保存先を選択して実行

## 出力仕様

| 設定 | 値 |
|------|-----|
| 解像度 | 1920×1080 (16:9) / 1080×1920 (9:16) |
| 映像コーデック | H.264 |
| 音声コーデック | AAC 192kbps |
| コンテナ | MP4 |
