# ClipFlow

複数の動画クリップを連結・合成して1つの動画として書き出すデスクトップアプリケーション。

## 特徴

- **クリップ連結**: 複数の動画クリップを順番につなぎ合わせる
- **2レーン構成**: 左右（または上下）に分割したレイアウトにも対応
- **トリミング**: 各クリップのイン点・アウト点を自由に設定
- **クロップ調整**: 表示位置とズーム倍率を調整
- **音量調整**: 各レーンの個別音量とバランスを調整
- **リアルタイムプレビュー**: 編集結果を確認しながら作業
- **高品質書き出し**: H.264/AAC形式でMP4出力

## 技術スタック

- Electron + React + TypeScript
- Vite (ビルドツール)
- Zustand (状態管理)
- Tailwind CSS (スタイリング)
- FFmpeg (動画処理)

## 開発環境セットアップ

### 必要条件

- Node.js 18以上
- npm

### インストール

```bash
git clone <repository-url>
cd video-editor
npm install
```

### 開発サーバー起動

```bash
npm run dev
```

### ビルド

```bash
npm run build
```

## 使い方

1. **動画を追加**: レーンの「+」ボタンから動画ファイル（MP4/MOV）を選択
2. **トリミング**: クリップを選択し、スライダーで使用範囲を調整
3. **クロップ調整**: クリップを選択し、表示位置をドラッグで調整
4. **音量調整**: プレビュー下部で各レーンの音量を調整
5. **プレビュー**: 再生ボタンまたはスペースキーで確認
6. **書き出し**: 「書き出し」ボタンから保存先を選択して実行

## 出力仕様

| 設定 | 値 |
|------|-----|
| 解像度 | 1920×1080 (16:9) / 1080×1920 (9:16) |
| 映像コーデック | H.264 |
| 音声コーデック | AAC 192kbps |
| コンテナ | MP4 |
