### 3. レーンエリア（OOUI の核心）
```
┌─ 左レーン ──────────────────────┐  ┌─ 右レーン ──────────────────────┐
│                                 │  │                                 │
│  ┌────────┐ ┌────────┐ ┌─────┐ │  │  ┌────────┐ ┌─────┐            │
│  │ ████   │ │ ████   │ │  ＋ │ │  │  │ ████   │ │  ＋ │            │
│  │ Clip 1 │ │ Clip 2 │ │     │ │  │  │ Clip 1 │ │     │            │
│  │ 5.2s   │ │ 3.8s   │ │     │ │  │  │ 8.5s   │ │     │            │
│  │ ▼選択中│ └────────┘ └─────┘ │  │  └────────┘ └─────┘            │
│  └────────┘                     │  │                                 │
│                                 │  │                                 │
│  レーン尺: 9.0s                 │  │  レーン尺: 8.5s                 │
└─────────────────────────────────┘  └─────────────────────────────────┘
```

**クリップカード（オブジェクト）の状態表現：**
| 状態 | 視覚表現 |
|------|----------|
| 通常 | グレー枠 |
| 選択中 | 青枠 + 影 |
| ドラッグ中 | 半透明 + 移動カーソル |
| エラー | 赤枠 + アイコン |

**操作：**
- クリップをクリック → トリムエディタに表示
- クリップをドラッグ → 並び替え
- ＋ボタン → ファイル選択 or ドロップゾーン表示

### 4. トリムエディタ（選択クリップの詳細ビュー）
```
┌─ トリムエディタ ─────────────────────────────────────────────────────┐
│                                                                       │
│  選択中: 左レーン - Clip 1                           [クリップ削除]  │
│                                                                       │
│  ┌────┬────┬────┬────┬────┬────┬────┬────┬────┬────┐                 │
│  │▓▓▓▓│▓▓▓▓│▓▓▓▓│▓▓▓▓│▓▓▓▓│░░░░│░░░░│░░░░│░░░░│░░░░│  サムネイル    │
│  └────┴────┴────┴────┴────┴────┴────┴────┴────┴────┘                 │
│       ▲ IN                 ▲ OUT                                      │
│                                                                       │
│  ├────●━━━━━━━━━━━━━━━━━━━●───────────────────────────────────┤      │
│  0.0s                                                        12.0s    │
│                                                                       │
│  IN:  [ 00:01.2 ]    OUT: [ 00:06.4 ]    使用尺: 5.2s                │
│        ← →                  ← →           （自動計算）               │
│                                                                       │
└───────────────────────────────────────────────────────────────────────┘
```

**サムネイルストリップ：**
- 動画全体を10分割程度でサムネイル表示
- IN〜OUT範囲: ハイライト（▓）
- 範囲外: 暗く表示（░）

**レンジスライダー：**
- 2ハンドル（IN / OUT）
- ドラッグで調整
- スナップ: 0秒、末尾、0.5秒刻み

**数値入力：**
- mm:ss.s 形式
- キーボード: ← → で ±0.1秒、Shift で ±1秒

## OOUI チェック

| 原則 | 適用 |
|------|------|
| オブジェクトが知覚できる | クリップがカードとして常に表示 |
| 状態を体現 | 選択中=青枠、範囲=ハイライト |
| オブジェクト→アクション | クリップ選択→トリム操作 |
| 直接操作 | ドラッグで並び替え、スライダーでトリム |

タスク指向を適用: 書き出しフロー（モーダルでステップ実行）
