# OOUI（オブジェクト指向UI）設計ガイド

## 1. OOUIとは

**OOUI（Object-Oriented User Interface）** は、タスク（動詞）ではなく**オブジェクト（名詞）を起点**としてUIを設計するアプローチ。

### 操作順序の違い

| アプローチ | 操作順序 | 例 |
|-----------|---------|-----|
| **OOUI** | オブジェクト → アクション | 写真を選ぶ → 削除する |
| **タスク指向** | アクション → オブジェクト | 削除する → 写真を選ぶ |

OOUIは「名詞→動詞」の順序で、人間の自然な思考パターンに沿っている。

---

## 2. OOUIの4原則

上野学氏の著書より：

1. **オブジェクトを知覚でき直接的に働きかけられる**
   - オブジェクトが画面上で視覚的に認識可能
   - 直接操作（ドラッグ、クリック等）で働きかけられる

2. **オブジェクトは自身の性質と状態を体現する**
   - オブジェクトの見た目がその状態を表す
   - 選択中、編集中、エラー等が視覚的にわかる

3. **オブジェクト選択→アクション選択の操作順序**
   - まず「何を」操作するか選ぶ
   - 次に「どうするか」を選ぶ

4. **すべてのオブジェクトが互いに協調しながらUIを構成する**
   - オブジェクト間の関係性が明確
   - 一貫したインタラクションパターン

## 3. 設計プロセス（3ステップ）

### ステップ1：オブジェクトの抽出

ユーザーのタスクやゴールから**名詞**を抽出し、主要オブジェクトを特定する。

**抽出のポイント：**
- ユーザーが操作・閲覧したいもの
- システムで管理すべきエンティティ
- 現実世界のメンタルモデルに対応するもの

### ステップ2：ビューの設計

各オブジェクトに対して2種類のビューを設計：

| ビュー種別 | 説明 | 例 |
|-----------|------|-----|
| **コレクション** | オブジェクトの一覧表示 | 動画クリップ一覧 |
| **シングル** | 個別オブジェクトの詳細 | クリップ編集画面 |

### ステップ3：レイアウトとナビゲーション

- オブジェクト間の関係性に基づくナビゲーション設計
- デバイスサイズに応じたレイアウト最適化
- コンテキストに応じた関連オブジェクトへの導線

---

## 4. OOUIのメリット

### ユーザーにとって
- **直感的**：日常生活と同じ感覚で操作可能
- **学習コスト低**：マニュアル不要で使える
- **自由度**：自分のペースで目的に到達
- **発見しやすい**：オブジェクトが見えているので探索しやすい

### 開発にとって
- **画面数削減**：オブジェクト中心で設計がシンプルに
- **再利用性**：オブジェクト単位でコンポーネント化しやすい
- **保守性**：変更影響範囲が明確
- **FE/BE連携**：データモデルとUIの対応が明確

## 5. タスク指向UIが適する場面

OOUIが万能ではない。以下の場合はタスク指向が適切：

| 条件 | 例 |
|------|-----|
| 操作対象が常に一定 | ATM（自分の口座のみ） |
| 特定ゴールへ確実に誘導したい | ウィザード形式 |
| 緊急時のミスなき操作 | 緊急通報アプリ |
| 初回利用時の導線 | 検索条件の絞り込み |

### 判断基準
> 「ユーザーの動作する対象は決まっているか？」
> - 決まっている（1つ）→ タスク指向
> - 決まっていない（複数）→ OOUI

---

## 6. 組み合わせパターン

### パターン1：段階的切り替え
- **初回**：タスク指向で選択肢を提示
- **継続利用**：OOUIで自由な操作

### パターン2：モード別適用
- **探索モード**：OOUI（自由にブラウズ）
- **実行モード**：タスク指向（確実に完了）

### パターン3：階層別適用
- **上位階層**：OOUI（オブジェクト一覧）
- **操作階層**：タスク指向（特定操作の実行）

## 7. 本プロジェクトへの適用

### 抽出されるオブジェクト

| オブジェクト | 説明 |
|-------------|------|
| **プロジェクト** | 編集セッション全体 |
| **レーン** | 左右の動画レーン |
| **クリップ** | 個別の動画ファイル（トリム情報含む） |
| **プレビュー** | 合成結果のプレビュー |
| **出力設定** | アスペクト比、音声モード等 |

### ビュー設計方針

```
[メイン画面: 1画面完結]
├── レーン（コレクション）
│   ├── クリップ（シングル: サムネイル+情報）
│   └── クリップ追加ボタン
├── トリムエディタ（選択クリップの詳細）
│   ├── サムネイルストリップ
│   ├── IN/OUTスライダー
│   └── 時間入力
├── プレビュー（合成結果）
└── 出力設定パネル
```

### OOUI適用ポイント

1. **クリップが主役**
   - クリップをクリック → トリム編集パネルが開く
   - クリップの状態（選択中、トリム範囲）が視覚的に明確

2. **直接操作**
   - クリップのドラッグで並び替え
   - スライダーのドラッグでIN/OUT調整
   - プレビューのスライダーで再生位置調整

3. **オブジェクトの可視性**
   - 全クリップが常に画面上に表示
   - 選択範囲がサムネイルでハイライト
   - レーン尺・出力尺が常に表示

### タスク指向を適用する箇所

- **書き出しフロー**：確実に完了させるためウィザード的進行
- **初回ガイド**：最初のクリップ追加を誘導
